## Proxy Personalizado + Overrides de DNS

`ProxyConfig` propaga un proxy HTTP/SOCKS y overrides de DNS por host
a través del transporte HTTP (httpx) y del WebSocket.

```python
from pyquotex import Quotex, ProxyConfig

proxy = ProxyConfig(
    url="http://user:pass@proxy.example.com:8080",
    verify_ssl=True,
    dns_overrides={"qxbroker.com": "1.2.3.4"},
    extra_headers={"X-Forwarded-For": "203.0.113.10"},
)

client = Quotex(
    email="me@example.com",
    password="...",
    proxy_config=proxy,
)
```

| Campo | Tipo | Función |
| --- | --- | --- |
| `url` | `str \| None` | URL completa — `http://`, `https://`, `socks5://`, `socks5h://`. |
| `verify_ssl` | `bool` | Desactivar para saltar verificación TLS (útil con DNS overrides a IP). |
| `dns_overrides` | `dict[str, str]` | Mapea hostname → IP. La URL se reescribe al IP y se preserva el `Host` original para SNI/cert. |
| `extra_headers` | `dict[str, str]` | Headers añadidos a toda petición HTTP y WebSocket. |
| `use_browser_tls` | `bool` | Cambia el backend HTTP a `curl_cffi` (TLS de navegador real). |
| `impersonate` | `str` | Perfil de navegador objetivo cuando `use_browser_tls=True`. Default `"chrome120"`. |

También puedes construir un `ProxyConfig` desde un dict (útil para
archivos de configuración):

```python
proxy = ProxyConfig.from_dict({
    "url": "socks5://h:1080",
    "dns_overrides": {"qxbroker.com": "1.2.3.4"},
})
```

> **Aviso sobre TLS.** Cuando `dns_overrides` reescribe una URL HTTPS
> a una IP cruda, la verificación de certificado por defecto fallará a
> menos que el servidor presente un cert válido para la IP. Usa
> `verify_ssl=False` o termina TLS en tu proxy.

## TLS con Impersonación de Navegador (curl_cffi)

Los sistemas modernos de detección de bots hacen fingerprint de TLS
(JA3/JA4) y HTTP/2. `httpx` emite una firma "Python" trivialmente
distinguible de un Chrome/Firefox real. Definir `use_browser_tls=True`
cambia el backend HTTP a
[`curl_cffi`](https://github.com/yifeikong/curl_cffi), que emite una
firma de navegador real.

```bash
pip install 'pyquotex[stealth]'
```

```python
proxy = ProxyConfig(
    url="http://residential-proxy:8080",
    use_browser_tls=True,
    impersonate="chrome120",  # o "firefox133", "safari17_2", "chrome116", …
)
client = Quotex(email="…", password="…", proxy_config=proxy)
```

Comportamiento:

- Con el extra `stealth` instalado, todas las peticiones HTTP pasan
  por `curl_cffi.AsyncSession`.
- Si el extra **no** está instalado, se registra un warning y el
  cliente cae al `httpx` por defecto — los scripts existentes siguen
  funcionando.
- El transporte WebSocket no se altera; solo el fingerprint HTTP.

## Bootstrap de Perfil Multilogin

`MultiloginConfig` integra con el agente local v1 o la API de nube v3
de [Multilogin](https://multilogin.com). En `connect()`, el cliente
inicia el perfil configurado, obtiene su proxy + user-agent y los
hereda automáticamente.

```python
from pyquotex import Quotex, MultiloginConfig

multilogin = MultiloginConfig(
    profile_id="00000000-0000-0000-0000-000000000000",
    folder_id="my-folder",          # requerido en v3
    token="<bearer-token>",         # requerido en v3
    api="v3",                       # o "v1" para el agente local
    auto_start=True,
    auto_stop=True,
)

client = Quotex(email="…", password="…", multilogin=multilogin)
await client.connect()              # arranca el perfil, hereda proxy/UA
# … operar …
await client.close()                # detiene el perfil
```

Si también pasas un `proxy_config`, este tiene precedencia sobre el
proxy del perfil. De lo contrario, el proxy del perfil se envuelve en
un `ProxyConfig` automáticamente.

En redes corporativas, `MultiloginClient` acepta un kwarg `proxy` para
que la llamada al propio agente Multilogin salga por el gateway:

```python
from pyquotex import MultiloginClient

ml = MultiloginClient(multilogin, proxy="http://corp-proxy:8080")
profile = await ml.start_profile()
```

## Monitoreo Avanzado de Sentimiento

`SentimentMonitor` envuelve el stream `sentiment` existente con
historial en ventana, detección estadística de anomalías, callbacks
de threshold y análisis de divergencia precio/sentimiento.

Habilítalo en el cliente:

```python
from pyquotex import Quotex, SentimentThresholds

thresholds = SentimentThresholds(
    extreme_bullish=0.7,
    extreme_bearish=-0.7,
    spike_zscore=2.5,
    divergence_window=20,
    divergence_threshold=-0.5,
)

client = Quotex(
    email="…", password="…",
    enable_sentiment_monitor=True,
    sentiment_thresholds=thresholds,
)

monitor = client.get_sentiment_monitor()

async def on_signal(signal):
    print(f"{signal.asset} -> {signal.kind} bias={signal.snapshot.bias:.2f}")

monitor.on_signal(on_signal)
```

### Tipos de señal

| Tipo | Disparo |
| --- | --- |
| `extreme_bullish` | Bias con signo ≥ `extreme_bullish`. |
| `extreme_bearish` | Bias con signo ≤ `extreme_bearish`. |
| `spike` | Z-score absoluto del bias actual sobre la ventana de historial ≥ `spike_zscore`. |
| `divergence` | Correlación de Pearson entre bias y precio sobre `divergence_window` ≤ `divergence_threshold`. |

Existe un cooldown de 5 segundos por `(asset, kind)` para evitar spam
de señales repetidas durante extremos sostenidos.

### Leyendo estado directo

```python
latest = monitor.latest("EURUSD")        # SentimentSnapshot o None
history = monitor.history("EURUSD")      # list[SentimentSnapshot]
```

## Persistencia + Correlación Cross-Asset de Sentimiento

`SentimentStore` es una capa SQLite que persiste cada muestra como
filas `(asset, timestamp, bullish, bearish, price)`.
`SentimentCorrelationAnalyzer` deriva correlaciones cross-asset y
pares divergentes desde el monitor en vivo o desde el store.

```python
from pyquotex import SentimentStore, SentimentCorrelationAnalyzer

store = SentimentStore("sentiment.db")
monitor.store = store      # graba cada feed() automáticamente

# … correr un rato …

analyzer = SentimentCorrelationAnalyzer(monitor=monitor)
matrix = analyzer.correlation_matrix(
    ["EURUSD", "GBPUSD", "USDJPY"], window=30
)
divergent_pairs = analyzer.find_divergences(
    ["EURUSD", "GBPUSD", "USDJPY"], window=30, threshold=-0.4
)
```

| Método | Devuelve |
| --- | --- |
| `SentimentStore.write(snap, price=...)` | Persiste una muestra (idempotente en `(asset, ts)`). |
| `SentimentStore.query(asset, start=, end=, limit=)` | Snapshots en orden ASC; `limit` devuelve los MÁS ANTIGUOS N. |
| `SentimentStore.query_latest(asset, limit=)` | Los N snapshots más recientes en orden ASC. |
| `SentimentStore.assets()` | Activos distintos en el store. |
| `SentimentCorrelationAnalyzer.correlation_matrix(assets, window=)` | `dict[(a, b), pearson_corr]`. |
| `SentimentCorrelationAnalyzer.find_divergences(assets, window=, threshold=)` | `[(a, b, corr), …]` ordenados por correlación ASC. |

El analyzer puede usar solo el store (útil para backtests):

```python
analyzer = SentimentCorrelationAnalyzer(store=store)
```

## Auto-Reconexión con Replay de Suscripciones

`ReconnectSupervisor` corre como tarea supervisora en la API y, al
desconectarse, reconecta con backoff exponencial + jitter. Tras un
reconnect exitoso, replaya el modo de cuenta capturado y cada
suscripción de velas / all-size / mood.

```python
from pyquotex import Quotex, ReconnectPolicy

policy = ReconnectPolicy(
    enabled=True,
    max_attempts=-1,        # ilimitado
    initial_delay=1.0,
    max_delay=60.0,
    backoff_factor=2.0,
    jitter=0.25,
)

client = Quotex(email="…", password="…", reconnect_policy=policy)
```

La auto-reconexión está **activada por defecto** — pasa
`auto_reconnect=False` (o `ReconnectPolicy(enabled=False)`) para
desactivar.

### Observabilidad

```python
sup = client.api.reconnect_supervisor
print(sup.stats.attempts, sup.stats.successful_reconnects)
print(sup.stats.last_disconnect_at, sup.stats.last_reconnect_at)
print(sup.stats.last_error)
```

### Hook de rehidratación

```python
async def warm_caches():
    await client.get_balance()

sup.on_reconnect(warm_caches)
```

El supervisor recaptura el estado de suscripciones al inicio de cada
iteración, así que las suscripciones añadidas por tu código entre
conexiones se preservan en la próxima caída.

## Dependencias Opcionales

Extras opcionales declarados en `pyproject.toml`:

| Extra | Instalación | Añade |
| --- | --- | --- |
| `fast` | `pip install 'pyquotex[fast]'` | `orjson` para parseo JSON más rápido. |
| `socks` | `pip install 'pyquotex[socks]'` | `httpx[socks]` para URLs `socks5://`. |
| `stealth` | `pip install 'pyquotex[stealth]'` | `curl_cffi` para TLS de navegador real. |

Combina extras con comas:
`pip install 'pyquotex[fast,socks,stealth]'`.
