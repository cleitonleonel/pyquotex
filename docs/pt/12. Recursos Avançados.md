## Proxy Customizado + Overrides de DNS

`ProxyConfig` propaga um proxy HTTP/SOCKS e overrides de DNS por host
através do transporte HTTP (httpx) e do WebSocket.

```python
from pyquotex import Quotex, ProxyConfig

proxy = ProxyConfig(
    url="http://user:pass@proxy.example.com:8080",
    verify_ssl=True,
    dns_overrides={"qxbroker.com": "1.2.3.4"},
    extra_headers={"X-Forwarded-For": "203.0.113.10"},
)

client = Quotex(
    email="me@example.com",
    password="...",
    proxy_config=proxy,
)
```

| Campo | Tipo | Função |
| --- | --- | --- |
| `url` | `str \| None` | URL completa — `http://`, `https://`, `socks5://`, `socks5h://`. |
| `verify_ssl` | `bool` | Desative para pular verificação de TLS (útil com DNS overrides para IP). |
| `dns_overrides` | `dict[str, str]` | Mapeia hostname → IP. A URL é reescrita para o IP e o `Host` original é preservado para SNI/cert. |
| `extra_headers` | `dict[str, str]` | Headers adicionados a toda requisição HTTP e ao WebSocket. |
| `use_browser_tls` | `bool` | Troca o backend HTTP para `curl_cffi` (TLS de navegador real). |
| `impersonate` | `str` | Perfil de navegador alvo quando `use_browser_tls=True`. Padrão `"chrome120"`. |

Você também pode construir um `ProxyConfig` a partir de um dict
(útil para arquivos de configuração):

```python
proxy = ProxyConfig.from_dict({
    "url": "socks5://h:1080",
    "dns_overrides": {"qxbroker.com": "1.2.3.4"},
})
```

> **Atenção sobre TLS.** Quando `dns_overrides` reescreve uma URL HTTPS
> para um IP cru, a verificação de certificado padrão falha a menos que
> o servidor apresente um certificado válido para o IP. Use
> `verify_ssl=False` ou termine TLS no seu proxy.

## TLS com Impersonação de Navegador (curl_cffi)

Sistemas modernos de detecção de bots fazem fingerprint de TLS
(JA3/JA4) e HTTP/2. O `httpx` emite uma assinatura "Python" facilmente
distinguível de um Chrome/Firefox real. Definir `use_browser_tls=True`
troca o backend HTTP para
[`curl_cffi`](https://github.com/yifeikong/curl_cffi), que emite uma
assinatura de navegador real.

```bash
pip install 'pyquotex[stealth]'
```

```python
proxy = ProxyConfig(
    url="http://residential-proxy:8080",
    use_browser_tls=True,
    impersonate="chrome120",  # ou "firefox133", "safari17_2", "chrome116", …
)
client = Quotex(email="…", password="…", proxy_config=proxy)
```

Comportamento:

- Com o extra `stealth` instalado, todas as requisições HTTP passam
  por `curl_cffi.AsyncSession`.
- Se o extra **não** estiver instalado, é registrado um warning e o
  cliente cai de volta no `httpx` — scripts existentes continuam
  funcionando.
- O transporte WebSocket não é alterado; apenas o fingerprint HTTP.

## Bootstrap de Perfil Multilogin

`MultiloginConfig` integra com o agente local v1 ou a API de nuvem v3
do [Multilogin](https://multilogin.com). No `connect()`, o cliente
inicia o perfil configurado, busca o proxy + user-agent e os herda
automaticamente.

```python
from pyquotex import Quotex, MultiloginConfig

multilogin = MultiloginConfig(
    profile_id="00000000-0000-0000-0000-000000000000",
    folder_id="my-folder",          # obrigatório no v3
    token="<bearer-token>",         # obrigatório no v3
    api="v3",                       # ou "v1" para o agente local
    auto_start=True,
    auto_stop=True,
)

client = Quotex(email="…", password="…", multilogin=multilogin)
await client.connect()              # inicia o perfil, herda proxy/UA
# … operar …
await client.close()                # para o perfil
```

Se você passar também um `proxy_config`, ele tem precedência sobre o
proxy do perfil. Caso contrário, o proxy do perfil é embrulhado em um
`ProxyConfig` automaticamente.

Em redes corporativas, `MultiloginClient` aceita um kwarg `proxy` para
que a chamada ao próprio agente Multilogin saia pelo gateway:

```python
from pyquotex import MultiloginClient

ml = MultiloginClient(multilogin, proxy="http://corp-proxy:8080")
profile = await ml.start_profile()
```

## Monitoramento Avançado de Sentimento

`SentimentMonitor` envolve o stream `sentiment` existente com
histórico em janela, detecção estatística de anomalias, callbacks de
threshold e análise de divergência preço/sentimento.

Habilite-o no cliente:

```python
from pyquotex import Quotex, SentimentThresholds

thresholds = SentimentThresholds(
    extreme_bullish=0.7,
    extreme_bearish=-0.7,
    spike_zscore=2.5,
    divergence_window=20,
    divergence_threshold=-0.5,
)

client = Quotex(
    email="…", password="…",
    enable_sentiment_monitor=True,
    sentiment_thresholds=thresholds,
)

monitor = client.get_sentiment_monitor()

async def on_signal(signal):
    print(f"{signal.asset} -> {signal.kind} bias={signal.snapshot.bias:.2f}")

monitor.on_signal(on_signal)
```

### Tipos de sinal

| Tipo | Disparo |
| --- | --- |
| `extreme_bullish` | Bias com sinal ≥ `extreme_bullish`. |
| `extreme_bearish` | Bias com sinal ≤ `extreme_bearish`. |
| `spike` | Z-score absoluto do bias atual sobre a janela de histórico ≥ `spike_zscore`. |
| `divergence` | Correlação de Pearson entre bias e preço sobre `divergence_window` ≤ `divergence_threshold`. |

Existe um cooldown de 5 segundos por `(asset, kind)` para evitar spam
de sinais repetidos durante extremos sustentados.

### Lendo estado direto

```python
latest = monitor.latest("EURUSD")        # SentimentSnapshot ou None
history = monitor.history("EURUSD")      # list[SentimentSnapshot]
```

## Persistência + Correlação Cross-Asset de Sentimento

`SentimentStore` é uma camada SQLite que persiste cada amostra como
linhas `(asset, timestamp, bullish, bearish, price)`.
`SentimentCorrelationAnalyzer` deriva correlações cross-asset e pares
divergentes a partir do monitor ao vivo ou do store.

```python
from pyquotex import SentimentStore, SentimentCorrelationAnalyzer

store = SentimentStore("sentiment.db")
monitor.store = store      # grava cada feed() automaticamente

# … rodar por um tempo …

analyzer = SentimentCorrelationAnalyzer(monitor=monitor)
matrix = analyzer.correlation_matrix(
    ["EURUSD", "GBPUSD", "USDJPY"], window=30
)
divergent_pairs = analyzer.find_divergences(
    ["EURUSD", "GBPUSD", "USDJPY"], window=30, threshold=-0.4
)
```

| Método | Retorna |
| --- | --- |
| `SentimentStore.write(snap, price=...)` | Persiste uma amostra (idempotente em `(asset, ts)`). |
| `SentimentStore.query(asset, start=, end=, limit=)` | Snapshots em ordem ASC; `limit` retorna os MAIS ANTIGOS N. |
| `SentimentStore.query_latest(asset, limit=)` | Os N snapshots mais recentes em ordem ASC. |
| `SentimentStore.assets()` | Ativos distintos no store. |
| `SentimentCorrelationAnalyzer.correlation_matrix(assets, window=)` | `dict[(a, b), pearson_corr]`. |
| `SentimentCorrelationAnalyzer.find_divergences(assets, window=, threshold=)` | `[(a, b, corr), …]` ordenados por correlação ASC. |

O analyzer pode usar apenas o store (útil para backtests):

```python
analyzer = SentimentCorrelationAnalyzer(store=store)
```

## Auto-Reconexão com Replay de Subscrições

`ReconnectSupervisor` roda como tarefa supervisora na API e, ao
desconectar, reconecta com backoff exponencial + jitter. Após um
reconnect bem-sucedido, replaya o modo de conta capturado e cada
subscrição de candles / all-size / mood.

```python
from pyquotex import Quotex, ReconnectPolicy

policy = ReconnectPolicy(
    enabled=True,
    max_attempts=-1,        # ilimitado
    initial_delay=1.0,
    max_delay=60.0,
    backoff_factor=2.0,
    jitter=0.25,
)

client = Quotex(email="…", password="…", reconnect_policy=policy)
```

Auto-reconexão é **ativada por padrão** — passe `auto_reconnect=False`
(ou `ReconnectPolicy(enabled=False)`) para desativar.

### Observabilidade

```python
sup = client.api.reconnect_supervisor
print(sup.stats.attempts, sup.stats.successful_reconnects)
print(sup.stats.last_disconnect_at, sup.stats.last_reconnect_at)
print(sup.stats.last_error)
```

### Hook de reidratação

```python
async def warm_caches():
    await client.get_balance()

sup.on_reconnect(warm_caches)
```

O supervisor recaptura o estado de subscrições no topo de cada
iteração, então subscrições adicionadas pelo seu código entre
conexões são preservadas no próximo drop.

## Dependências Opcionais

Extras opcionais declarados em `pyproject.toml`:

| Extra | Instalação | Adiciona |
| --- | --- | --- |
| `fast` | `pip install 'pyquotex[fast]'` | `orjson` para parse JSON mais rápido. |
| `socks` | `pip install 'pyquotex[socks]'` | `httpx[socks]` para URLs `socks5://`. |
| `stealth` | `pip install 'pyquotex[stealth]'` | `curl_cffi` para TLS de navegador real. |

Combine extras com vírgulas:
`pip install 'pyquotex[fast,socks,stealth]'`.
